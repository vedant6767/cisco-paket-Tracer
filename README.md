# Cisco Packet Tracer LAN Mini Project

## Project Description
A Local Area Network built using Cisco Packet Tracer.

## Devices Used
- 1 Router
- 2 Switches
- 4 PCs

## IP Addressing
- PC1: 192.168.1.10
- PC2: 192.168.1.11
- PC3: 192.168.1.12
- PC4: 192.168.1.13

## Result
Successful communication was verified using the ping command across the two switches.
